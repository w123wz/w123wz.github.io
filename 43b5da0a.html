Butterfly 主题自定义页面踩过的坑

发表于2026-09-30|更新于2026-10-02|经验分享
|浏览量:

背景

在给 Butterfly 主题添加自定义页面（标签云、分类卡片、统计页、项目页）的过程中，遇到了不少问题，记录一下。

问题一：front-matter 的 layout vs type

Butterfly 的 page.pug 里用 case page.type 来匹配渲染哪种模板，而不是 layout。

问题二：pug script 块里 !{} 插值嵌套花括号

script. 块里用 !{} 输出 JSON 时，如果内部有箭头函数 + 对象字面量，pug 会搞混花括号。

问题三：permalink 里用了无效变量

_config.yml 里 permalink 写成了：

:posts 不是 Hexo 内置变量，会被解析成 undefined，导致生成的文章链接是 undefined/43b5da0a.html，.deploy_git 里也会出现一个奇怪的 undefined/ 目录。

问题四：想自定义文章目录，发现 post_dir 是硬编码的

原本想把文章从 source/_posts/ 改到 source/articles/，查了 Hexo 5.7.0 的源码 node_modules/hexo/dist/plugins/processor/post.js:12：

_config.yml 里没有 post_dir 这个配置项，Hexo 文章目录必须是 source/_posts/。

变通方案：在 _posts 里建子目录分组就行，Hexo 会递归扫描所有子目录的 md 文件。

问题五：手动新建 md 文件，abbrlink 算出了 ‘0’

手动右键新建的 md 文件是空白的，front-matter 里只有 abbrlink: '0'。

原因：abbrlink 插件根据文章内容算 hash，空内容算出来就是 0，而且多个空文件会算出一样的 abbrlink，导致链接冲突。

解决：用 hexo new 命令创建，自动套用 scaffold 模板，等文件有内容后 abbrlink 插件会算出正确值。

问题五补充：hexo new 创建的文章也没有 abbrlink

用 hexo new "标题" -p "路径" 创建出来的文件 front-matter 里没有 abbrlink，是正常的。

原因：abbrlink 是 Hexo 插件（hexo-abbrlink），它不是在创建文件时工作的，而是在 hexo g / hexo s 渲染时才根据文章内容算 crc32 hash，然后自动写回 md 文件。

所以流程是：先创建 → 写内容 → 跑 hexo g/s → abbrlink 自动生成，不用手动管。

规则：-p "子目录/文件名"，缺了斜杠后面的文件名就会被当成文章名。

问题八：项目简介的 link 怎么填文章地址

projects.yml 里每个项目有个 link 字段，指向文章的话填：

每篇文章的 abbrlink 在 front-matter 里可以找到，或者终端跑 hexo list post 查看所有文章的 abbrlink。

总结

  • 自定义页面记得在 page.pug 里加 when 'your-type' 分支
  • 所有 JSON 插值都在 pug 逻辑变量里算好，script. 块只做纯字符串替换
  • permalink 别用 :posts，是无效变量，文章链接建议直接用 :abbrlink.html
  • Hexo 文章目录不能改，_posts 里建子目录分组即可
  • 新文章一律用 hexo new "标题" -p "子目录/文件名" 创建，别手动新建
  • target='_blank' 按需使用，站内跳转不用开新标签页
  • 项目 link 用 abbrlink 格式：/<abbrlink>.html
