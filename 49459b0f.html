整体架构概览

项目采用了 Spring Security + JWT（Auth0 实现）+ MyBatis-Plus 的技术栈来实现认证授权。涉及的核心文件有 7 个，职责分工如下：

层次 文件 职责
Controller controller/User.java 暴露 /login、/current、/logout 等 REST 接口
Service service/UserService.java 登录业务逻辑（查用户、验密码、生成 token）
JWT 工具 util/JwtTokenUtil.java Token 的生成、解析、验证、黑名单管理
过滤器 util/JwtAuthticationFilter.java 拦截请求、提取并验证 Token、设置 Security 上下文
安全配置 config/SecurityConfig.java 定义公开路径、配置过滤器链
JWT 配置 config/JwtConfig.java 从 application.yml 读取密钥、过期时间等
转换器 service/convert/UserConvert.java Entity → DTO 的对象映射

util/JwtAuthenticationFilter.java 继承自 OncePerRequestFilter，确保每个请求只被处理一次，避免重复处理。
